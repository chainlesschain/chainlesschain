## 已验证行为

- 实际 `ProjectGoalMonitoringEngine` 在原生 SQLite 事务内一并保存检查、预算使用、建议观察及通知投影；投影写入失败时全部回滚。
- 通知只保存通用文案和引用，未复制目标说明、任务或记忆正文，也不触发操作系统通知。
- 相同风险仅推进来源及检查时间，保留已读；按 occurrence 重试不重复投递。大任务集不受小型动作输入摘要限制影响。
- `silent` 与 IANA 时区静默时段生效，覆盖跨午夜与夏令时；数据库重开后补投递，暂停、结束、到期和控制变化阻止旧待投递通知。
- 主进程列表、计数、打开及已读操作重新核验身份、登录代次、窗口、frame、数据库与源检查。撤权或摘要损坏后，不回退显示缓存文案。
- 前端同步监听登录变化，清除旧投影并丢弃迟到结果；同设备重新登录、已读与导航之间的权限变化有回归覆盖。
- 通知点击两次复核来源，使用宿主返回的最小导航目标；项目页直接读取指定目标，不局限列表前 20 项。URL 仅为导航提示，不提供权限。
- 通知设置使用显式版本保存；身份/版本变化清草稿，不确定的保存需刷新核对后重试。

## 验证边界与运行环境

- SQLite 为真实驱动；测试存储 opener、Electron、IPC 与路由边界为替身。**尚未执行真实 Electron GUI 旅程或真实业务效果评估。**
- 前端为真实 Vue 组件及 Happy DOM。当前工作区缺少部分 UI 依赖，使用 Temp 下隔离安装的 `vue-router`、`ant-design-vue`、图标包及 Happy DOM resolver；未修改项目依赖或 lockfile。
- 隔离打包只安装公共入口的依赖闭包，不以本地源码直接 require 代替打包验证。初次 npm 缓存写入受沙箱限制；许可重跑及可写 Temp 缓存下的验证已通过。
- 已投递且仍获授权的通知保留历史检查含义；暂停、结束、过期及修订不会把历史记录冒充为当前检查。
- 界面展示最近 50 条授权目标通知，未读徽标对应此页；不向旧检查补造通知。
- 模型输出阶段记忆授权、其余实施任务、准确候选提交的远端三平台发布门仍未完成。本证据不等同于发布批准。
