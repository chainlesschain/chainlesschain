这里的 Memory 指项目指令导入的文件，例如 `cc.md` 中的 `@memory.md`。本批没有刷新所有结构化 Memory 数据库、启动时 recall 或历史摘要中已经出现的文本，也不把文件刷新解释为全量 Memory 恢复完成。

实现提取 [compaction-host-context.js](../../packages/cli/src/runtime/compaction-host-context.js)，由宿主提供同步重建函数。core 在更新前核对原始历史快照，再将新的宿主基础消息投影进 micro-compaction 候选；压缩后只更新运行时上下文。独立评审和 hermetic 路径不因此读取额外项目文件。REPL 在下一次模型回合前重建基础消息，现有注册前缀控制器保留启动上下文与历史摘要的区别。

[集成测试](../../packages/cli/__tests__/integration/compaction-project-context-refresh.test.js) 的五个边界场景使用可控 compressor，分别覆盖成功、失败回退、摘要期间更新、文件删除和真实本地 `PreCompact` 命令 hook。两个 canonical 保存 / 恢复场景使用生产压缩路径，仅强制压缩调度阈值；固定消息可在预算内保留，因此不证明付费语义摘要的质量。所有模型响应均为注入夹具。MCP 宿主测试验证目录传递，不代替第二十八批真实 HTTP 传输测试。
