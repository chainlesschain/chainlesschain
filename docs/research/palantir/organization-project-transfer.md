# 双主体项目归属迁移

更新：2026-10-07。第八批 PAL ONT / POLICY 本地源码交付；既有同一所有者直接绑定仍独立使用。迁移服务、固定 IPC 与真实 Vue/SQLite 交互完成本地验证，未发布。

## 支持的归属变化

当前支持未绑定、draft/active 的规范项目转入原所有者所在的组织。原所有者须为该组织 active 成员，接收者须同时等于组织根 `owner_did` 并具有 active owner 成员行，双方 DID 必须不同。组织项目必须属于所选组织；相同 ID 不会自动映射。

迁移保留 `projects.user_id` 和 `binding.original_owner_did` 为原所有者，`bound_by_did` 记录接收组织所有者。权限切换由明确绑定完成，不改写原账号归属，不自动给任何一方授予任务权限。绑定后一般任务、风险和目标的个人入口继续拒绝，组织任务使用明确政策授权。

已绑定、已撤销绑定、组织之间转移、转回个人、双方账号所有权改写、非成员项目导入和历史设备 ID 转换不在本轮范围。撤销保留作用域 tombstone，不恢复个人访问。

## 两份真实确认

1. 组织所有者先在组织设置中配置本组织的工作流及目标规范项目 ID 的明确授权，再原生确认政策。未绑定项目 ID 只是调用者提供的配置提示；此步骤不会返回个人项目名称、所有者或任务正文。
2. 原项目所有者在“双主体项目迁移”选择目标组织和独立组织项目，预览双方身份及本项目的明确权限，原生确认转出。此时只保存 pending 同意，个人入口继续可用。
3. 目标组织所有者用自己的登录身份选择该同意，原生确认接收。接收仅传 `transferId`；主进程读取已保存证据，在最终 immediate 事务复核后原子完成绑定、消费、绑定事件及接收事件。
4. 双方可以独立核对迁移元数据和回执。请求者能撤回同意，当前组织所有者能拒绝接收；两者均使用原生确认，不建立绑定。关闭原生弹窗不提交。

原所有者的目的地目录仅返回本人 active 成员关系允许的组织及组织项目摘要。组织所有者的设置只读取自己的组织目录和政策。待接收记录不提供项目任务读取权限；旧角色、grants、普通 admin 或任务 approved 均不能替代两位所有者的同意。

## 固定证据、期限和原子性

`OrganizationProjectTransferService` 在独立的 `cc_organization_project_transfers` 表保存不可变同意。证据包含项目与组织项目、双方 DID、仅本项目的授权明细、政策摘要/epoch、组织来源 revision/摘要、项目来源 revision、数据库 schema revision 和固定期限。完整迁移快照最多 16 KiB，不含任务描述或原始幂等键；元数据查询不返回快照或授权明细。

期限最多 24 小时，重读、重试和取消旧记录不会延长。成员、组织根、个人任务、workspace、目录、政策、schema 或双方归属发生变化，包括修改后恢复原值，旧同意失效。个人任务在等待接收时仍能操作，其修改使旧迁移版本无法接收；不会自动生成新版同意或刷新期限。

同一规范项目或组织项目的未过期待处理同意互斥；换摘要、组织或期限不能绕过。旧直接绑定入口也检查互斥。旧政策已失效时，原所有者仍能撤回，当前组织所有者仍能拒绝。过期后不再接收。

接收确认之后再次核验双方身份、来源、未决个人动作、期限和当前映射。最终绑定、同意单次消费与两份接收/绑定事件在同一事务完成；事件、绑定或消费写入失败全部回滚，pending 同意保留。双连接并发和同意/接收幂等回读只产生一次绑定。

迁移回执仅允许记录中的已登录双方读取，不要求仍有 `task.read` 或成员资格。绑定撤销、当事人失去组织读取权限后，仍可以核对原 terminal 回执；这不会授予一般项目正文访问权限。记录摘要提供本库内容一致性，不是跨服务签名证明。

## IPC 和界面恢复

新增 8 个精确通道：`transfer-catalog`、`transfer-preview`、`transfer-submit`、`transfer-read`、`transfer-list`、`transfer-accept`、`transfer-cancel`、`transfer-reject`，均在 `organization-project:` 命名空间，由 `electronAPI.organizationProject` 暴露。组织通道合计 28 个，无通配授权。

转出回复丢失时按固定同意摘要查找，接收回复丢失时按迁移 ID 读回回执；不自动重试写入。读回已接收结果同步刷新任务区。项目/身份变化和身份/窗口/数据库失效会使旧请求代次失效，防止延迟迁移预览或元数据响应恢复旧内容；项目/政策拒绝清除待迁移预览，当事人元数据回执保持独立核对入口。到期时界面关闭接收按钮，后台仍依据事务时间复核。

本批同时修复共享任务读取将组织授权错误掩盖成 `ACTION_READ_FAILED` 的问题。明确的组织权限失败现在传到界面，使已有任务正文正确清除。
