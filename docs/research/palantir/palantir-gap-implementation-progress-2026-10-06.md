## 当前实现边界

- 删除只作用于规范化实体及其派生索引；raw archive 保留，后续显式导入/重派生可能恢复该实体，不等同隐私擦除或上游平台删除。
- 投影 revision 在源更新和依赖变化时递增，不是不可变 raw snapshot 版本。`metadata.derivation` 支持追踪当前索引投影，完整回答引用历史尚未完成。
- 当前两个宿主都使用内存 BM25/KG，没有接入生产向量目标。新 consumer 用于新的内存索引；固定 consumer 中未知结果的 running 投递不会按超时自动重放。
- 启动恢复最多处理 100 页、每页 1,000 条投递；剩余工作可查询、手工重试。已退役 ephemeral consumer 可显式预览/清理非 running 回执；崩溃疑似代、未登记历史代和生命周期标记可核查且保留。新增重试前容量预算；全局硬配额、跨进程协调和压缩仍未实施。
- 现有索引使用裸 ID。不同实体类型共用 ID（含 tombstone）时返回 `DERIVATION_ID_CONFLICT`，需修复身份冲突，不能通过反复重试消除。
- 项目详情的个人与组织工作区已接入规范创建/描述、当前身份、原生确认和原子回执；组织路径使用明确授权、持久提议与不可变多级审批，第九批补齐风险，第十批补齐共享目标/手动检查，第十一批补齐有期限周期巡检。旧个人规范入口已收口，其余 10 个未受控规范变更入口拒绝执行。附属评论/清单、看板、旧团队 RBAC、其他对象/动作及组织目标动作/验收/记忆仍待统一迁移。设备 ID 归属和双主体所有权不自动迁移，不生成样例业务数据填充页面。
- 本地动作回执的摘要提供库内内容一致性，不是独立签名或外部不可改写证据；未知 admission 没有自动恢复或强制重放入口。
- CLI 风险评估仍使用未认证离线快照；桌面检查使用当前身份授权和事务读取。第五批完成个人描述风险来源与 admission/确认/ActionRun 绑定，第九批完成组织描述/创建风险与多级审批绑定、共享历史和原生人工核对；检索/回答及其他动作尚未接入，仍不证明实际业务风险、模型质量或费用效果。风险引用不能替代动作完整行版本。
- PDH 的 CLI/WS/IPC 沿用既有本地/共享 vault 权限边界；adapter/scope 只是查询筛选，尚未新增该数据域的对象级访问策略或前端操作页。
- 本地环境为 Windows / Node `22.22.2`。未运行仓库全量测试、真实桌面/IDE 操作旅程、Linux/macOS 发布矩阵、真实租户或模型业务验收。
