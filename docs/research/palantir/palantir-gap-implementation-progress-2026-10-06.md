## 本批实现边界

- 自动化连接器仍是目录与模拟能力。本批不宣称新增真实 Gmail、Slack、GitHub 等外部动作。
- RAG 指纹与写入串行状态位于单进程内；向量适配器须保证按 ID 幂等更新。调用方须重放最新文档，尚未增加持久化重试队列；现有 registry 对 sink 返回错误的完整处理仍需后续改进。
- 历史状态通过读取投影修正，保留原始审计行。对无充分证据的记录不补造真实执行回执。
- 桌面验证使用 Node 环境和 Electron 替身，未运行完整桌面构建或界面操作旅程。
- 当前为 Windows / Node `22.22.2` 本地验证；Linux/macOS 发布矩阵、真实租户、模型和业务验收尚未执行。
