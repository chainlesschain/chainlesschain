### 使用入口

```bash
cc hub derivation-status --json
cc hub derivation-state event <entity-id> --json
cc hub retry-derivations --adapter local-files --scope "<source-scope>" --limit 100 --json
cc hub delete-entity event <entity-id> --confirm --json
```

`retry-derivations` 每次处理 1–1,000 条投递，默认 100。删除结果分别报告规范化实体删除和派生处理结果，不能把前者当作所有目标已清除。

详细语义见 [Personal Data Hub 使用说明](../../../packages/personal-data-hub/README.md#durable-kgrag-projections-unreleased-2026-10-06) 和 [CLI 使用说明](../../../packages/cli/README.md)。

## 当前实现边界

- 删除只作用于规范化实体及其派生索引；raw archive 保留，后续显式导入/重派生可能恢复该实体，不等同隐私擦除或上游平台删除。
- 投影 revision 在源更新和依赖变化时递增，不是不可变 raw snapshot 版本。`metadata.derivation` 支持追踪当前索引投影，完整回答引用历史尚未完成。
- 当前两个宿主都使用内存 BM25/KG，没有接入生产向量目标。新 consumer 用于新的内存索引；固定 consumer 中未知结果的 running 投递不会按超时自动重放。
- 启动恢复最多处理 100 页、每页 1,000 条投递；剩余工作可查询、手工重试。旧 consumer 的回执仍保留在加密库，清理与压缩策略待实施。
- 现有索引使用裸 ID。不同实体类型共用 ID（含 tombstone）时返回 `DERIVATION_ID_CONFLICT`，需修复身份冲突，不能通过反复重试消除。
- 业务对象契约暂为共享接口基础；结构合法不证明真实授权、审批、执行成功或证据真实性，尚未接入业务写入入口。
- CLI/WS/IPC 沿用既有本地/共享 vault 权限边界；adapter/scope 只是查询筛选，尚未新增对象级访问策略或前端操作页。
- 本地环境为 Windows / Node `22.22.2`。未运行仓库全量测试、真实桌面/IDE 操作旅程、Linux/macOS 发布矩阵、真实租户或模型业务验收。
