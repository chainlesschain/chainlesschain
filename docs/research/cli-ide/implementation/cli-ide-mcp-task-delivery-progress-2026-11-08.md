**实际行为**

新增 mcp tasks deliver <local-id> --session <session-id>，把已经保存并结算的结果交付到原 canonical 会话。后续使用真实用户输入继续该会话，headless 与 REPL 恢复桥接都能取得同一份外部参考。

一个 mcp_task_delivery 事件同时确定消费标识与可恢复消息，绑定原会话、本地任务 ID、调用账本、result_saved 事件 hash、完整结果摘要、渲染版本和参考消息摘要。没有单独追加“已消费”与消息两步。写入在 canonical 事务锁内核对完整投影，返回前再验证提交结果；重复调用返回原事件，不再次追加或领取远端结果。

参考载体使用 assistant role 和固定外部数据说明，没有伪造工具调用、用户要求、模型回答或 usage。结果不成为 currentUserTask，也不进入独立 review 的原始用户需求；kernel 将其保留为 external 数据。正文最多 64 KiB，超过时显式标记摘录，完整结果仍可单独读取。结果进入上下文后仍受后续规划及投影约束，不保证全部原始正文始终留在每次请求中。

续跑需要真实用户指令接在参考消息后。不能把末尾 assistant 引用当作模型调用启动条件；Claude 4.6 及后续模型不支持这种 assistant prefill。[官方错误说明](https://platform.claude.com/docs/en/api/errors) 本批实测的 Anthropic 线格式会剥离 name，因此来源说明放在正文中，安全性不依赖 name 字段。

**来源与恢复**

- 同一套纯任务投影负责 IO 写入、完整验链读取和来源核对；普通分页、history、host snapshot 以及 canonical resume 都识别该事件，避免压缩前后显示不一致。
- 验证模式在检查真实结果后只保留结果摘要、渲染摘要和必要状态，不保留全部结果正文。原调用历史仍按原恢复规则保留。
- fork 复制完整父日志时，先验证父来源段，再依据真实 fork 前缀 hash/count、原 generation 合同和 lineage 切换作用域。子会话保留一次外部参考，不继承父任务控制表或交付身份。
- 嵌套 fork、缺 generation 的旧来源纯投影用例，以及坏 call / task / delivery 后接合法 lineage 均覆盖。来源错误不能通过切换作用域清除；没有合法边界的外来来源也不能取得目标会话身份。
- 原 requested-session 调用恢复视图保持保守，父调用带来的外来记录门禁没有放宽。fork 中新 MCP 操作仍可能被该既有门禁限制。
- call/task/generation 验证从 IO 层提为共享纯模块，保留旧导入路径和错误类身份。冷进程禁止加载 IO 模块时，纯投影仍能导入；不在投影回调中重入会话读取。
