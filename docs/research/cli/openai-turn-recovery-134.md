# OpenAI terminated 与 36+9 失败根因修复

用户补充截图只显示 `terminated`。本机对应会话在已完成五个工具调用后，下一次 OpenAI 调用约 1023 秒后以 `provider_call_failed` 结束；该日志没有记录底层异常细节，不能据此断言某个 HTTP 状态或账户不可用。

修复前用受控回归实际复现三项问题：JSON 读取抛出 `TypeError: terminated` 后没有重试；完成 Responses 事件后继续读取连接；超时处理等待永不结束的 reader.cancel。三个新增检查均先失败，再随修复通过。JSON 请求现在还有独立请求期限和取消传播。HTTP/provider 拒绝、部分工具调用、可见输出、严格用量观察失败与已持久化工作流的禁止重放规则保留。
