# 组织项目、共享目标与多级审批

> 2026-10-10 公开回读：CLI **0.166.96**、Agent SDK **0.2.14**、Open VSX **0.37.140**、JetBrains **0.4.158** 已公开，两个 IDE 均推荐 CLI `0.166.96`，准确发行提交 `da91e730d8`。Session Core **0.3.18**、Context/Memory Kernel **0.1.8**、PDH **0.4.64** 保持独立版本；产品 **v5.0.3.140** 仍来自 `f733f92cb9`。源码核对至 `main@2650447476`。本轮改善并发权限设置、JetBrains 审批卡片布局与失败诊断，补齐 Windows 私有工具链和清理取证；正式 36+9 评测保持 NOT_RUN，完整 native review 保持 NOT_ADMITTED，自动晋升 HOLD。 详见[本轮升级与诊断](https://docs.chainlesschain.com/chainlesschain/cli-ide-update-2026-10-10.html)。

## 概述

产品 v5.0.3.140 已包含组织任务工作台、双主体转移、组织风险、共享目标 / 巡检、目标动作审批、独立验收与共享记忆。目标由组织授权成员共享，保存目标不自动检查或写任务。

## 核心特性

- 组织管理员设置实际成员和项目权限；读取、创建、改描述、审批分别授权。
- 当前任务写入限创建任务与修改描述，逐级批准后仍需请求者原生确认。
- 共享目标跨成员共用预算，明确开启巡检、允许范围与验收条件。
- 独立验收重新核对事实，未决或未知动作阻止完成。
- 共享记忆分别检查读取/写入/删除权限，保留分类、精确版本和隐私控制。

## 系统架构

主进程从实际登录会话取得 DID，原生项目库检查组织成员、项目归属和策略版本。目标、风险、提议、审批、记忆引用和验收保存为持久记录；后台调度另用私有账本，两库结算投影可恢复。Memory Kernel 保存正文，目标保存精确版本引用。

## 使用示例

1. 真实登录后打开组织项目任务工作台，管理员按角色授予 task.read/create/update-description/approve。个人项目转移需个人所有者和组织侧授权主体分别确认，最终提交再次验证。
2. 查看任务、风险与动作血缘。风险检查只检测逾期和未完成直接依赖；不会调用外部连接器。
3. 在“组织项目目标”保存目标与预算。如需周期检查，明确开启巡检并配置当前版本；保存本身不启动。
4. 在“组织目标建议与审批”确认允许目标任务建议，选择建议，准备当前提议与预览，按组织策略逐级审批。
5. 全部审批通过后，由原请求者打开原生确认，核对对象、目标/策略版本和动作范围，再执行并查看原回执。
6. 在“组织目标独立验收”保存当前条件；有人工条件时由授权成员原生确认。先检查，再“原生确认后重新检查并完成目标”。
7. 在“组织目标共享记忆”选择事实/推断/备注，显式保存。授权成员可读、修正、撤权、删除；未决保存操作由原操作者查询和恢复。

## 配置参考

任务权限、goal 相关权限和 goal.memory.read/write/delete 各自检查。默认未允许目标动作；只在当前允许范围、组织审批策略和实际请求者身份均有效时执行。巡检、动作与验收共同消费目标预算，未知费用或动作结果保守占用。验收条件变化更新目标版本，旧人工确认不能用于新版本。

## 性能指标

目标/风险扫描与历史读取受源码合同限额和分页约束，预算耗尽显示阻塞。没有真实租户的长期吞吐、延迟或费用保证。共享记忆分页替换旧页，避免累计缓存正文。

## 测试覆盖

现有原生 SQLite、宿主 IPC、Renderer 与恢复回归覆盖权限撤销、版本冲突、逐级审批、未知结果、跨成员动作及独立验收。它们是本地控制证据，真实 Electron GUI、实际组织租户和业务效果尚待独立验收；不将历史批次数相加或当作新源码发行矩阵。

## 安全考虑

审批不授予额外权限；批准后仍检查实际成员、项目归属、策略、目标和对象版本。请求者身份变化、退出、锁定、窗口/frame 或连接切换会拒绝旧确认。共享记忆未自动注入模型或其他目标；读取前重验权限、版本与撤权代次。撤权/删除先禁止后续读取，再恢复清理；逻辑清理不认证备份物理擦除。

## 故障排查

| 现象                         | 处理                                                             |
| ---------------------------- | ---------------------------------------------------------------- |
| 找不到共享目标/记忆面板      | 升级到产品 .140 并检查实际成员、项目与 goal 权限；重新登录后读取 |
| 无权限或策略已改变           | 核对当前成员、项目与权限后刷新，不复用旧审批/预览                |
| 审批通过但没有写入           | 原请求者仍需原生确认；核对各级审批与实际执行权限                 |
| running/unknown 或结果不确定 | 查询原 requestId/intentId/ActionRun；不换 ID 重做                |
| 无法完成目标                 | 检查非空任务集、选定风险、跨成员及历史版本未决动作和人工记录     |
| partial 清理或保存未决       | 原操作者查询/恢复；保持读取拒绝，必要时清理未关联记忆            |
